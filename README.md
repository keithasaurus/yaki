# Yaki

Yaki, (pronouced like "hockey") is a micro-webframework.

## Another Micro Framework?
Yes, but this one is focused on asyncio.

## Aren't there others?
Yes, but this one is intended to be the easiest to understand, extend, 
and faster to develop useful things.

## Quickstart (uv)
This project now uses uv for dependency management and running tasks.

- Install uv: https://docs.astral.sh/uv/
- Create the virtualenv and install dependencies:
  - Runtime only: `uv sync`
  - With dev tools: `uv sync --all-groups`
- Run tests, type checks, and lint:
  - `uv run ./run_tests.sh`
- Add/remove dev dependencies (examples):
  - Add dev tool: `uv add -G dev ruff`
  - Remove dev tool: `uv remove -G dev ruff`

Notes:
- The previous Poetry configuration has been migrated to PEP 621 (`[project]`) with uv dependency groups.
- A `poetry.lock` file may still exist from earlier versions; it is no longer used. Prefer the `uv.lock` generated by `uv sync`.
